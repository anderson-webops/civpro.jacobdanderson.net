# Civ Pro 0.4.2: replay and artifact hardening

This release closes two source-backed security gaps without changing doctrine, scenario content, game balance, or the static production architecture.

- Replay, manual-save, and autosave restoration now accept only the existing `neutral`, `good`, and `bad` judge tones. The rendering sink also constrains the class value as defense in depth.
- Compatible 0.4.0 and 0.4.1 snapshots remain accepted when they contain a valid judge tone.
- The static artifact builder now preflights every allowlisted source path, rejects source-file and ancestor symlinks, hard links, traversal, and non-regular files, and verifies canonical containment under `public/` before changing `dist/client`. Copying uses a no-follow source descriptor with a second path/identity check and removes partial output on failure.
- Focused tests cover quote-only replay injection, legitimate tone and old-snapshot compatibility, source-file and parent-directory symlinks, broken links, hard links, a validation-to-copy swap, traversal, regular nested files, and binary assets.

Identity: application/package release 0.4.2, unchanged scenario catalog 0.4.1, content 2026-08-27.1, source review 2026-08-27. No new doctrine review or human classroom validation is claimed.
